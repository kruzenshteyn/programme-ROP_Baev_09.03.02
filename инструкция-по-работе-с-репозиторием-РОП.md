# Инструкция по работе с материалами ОПОП 09.03.02

> Это **новая локальная инструкция** для подготовки копии. Оригинальный одноимённый файл GitVerse не выгружен и может отличаться.

1. Для чтения материалов откройте [README](README.md) и ссылки на `УП.md`, `ЦКМВ.md`, `ОХОП.md`.
2. Для работы с дисциплинами используйте каталоги `Дисциплины/`, каждая папка содержит РПД, ФОС, лекции, занятия и тесты.
3. Сведения, требующие утверждения, помечены в замечаниях к согласованию и РПД.
4. Для публикации используйте отдельную ветку GitVerse, убедитесь в согласовании документов кафедрой.
5. Перед отправкой проверяйте `git status`, `git diff`, кросс-ссылки Markdown и корректность отображения русских названий.

## Клонирование с историей оригинала

```bash
git clone https://gitverse.ru/KAA85/programme-template.git
cd programme-template
git switch -c opop-09.03.02-2026
```

Затем перенесите необходимые файлы из локальной сборки, просмотрите изменения и сделайте коммит по принятому в вузе процессу. **Не используйте `git push --force`.**
