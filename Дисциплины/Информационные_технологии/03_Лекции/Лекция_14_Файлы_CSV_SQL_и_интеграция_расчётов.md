## 1. Основные понятия

CSV — текстовый формат обмена табличными данными; необходимо согласовать кодировку, разделитель, заголовки и формат чисел. Наличие кавычек и разделителей внутри значения требует корректного CSV-парсера.

## 2. Методы и инструменты

## 3. Проверка качества и ограничения

Связка Python и SQLite позволяет повторять операции с данными: создать таблицу, загрузить проверенные записи, выполнить запрос и получить отчёт. Используйте параметризованные запросы при работе со значениями извне.

## 8. Развёрнутый учебный пример и уточнения

### Безопасная загрузка CSV

```python
import csv
from pathlib import Path

with Path("Заказы_учебные.csv").open(encoding="utf-8-sig", newline="") as file:
    reader = csv.DictReader(file)
    orders = list(reader)
print(f"Прочитано строк: {len(orders)}")
```

Разделяйте входной файл и результат. Прежде чем писать в SQLite, убедитесь, что поля `price`, `quantity`, `discount` преобразованы с проверкой диапазонов. Не формируйте SQL, подставляя строку пользователя непосредственно внутрь текста запроса.
