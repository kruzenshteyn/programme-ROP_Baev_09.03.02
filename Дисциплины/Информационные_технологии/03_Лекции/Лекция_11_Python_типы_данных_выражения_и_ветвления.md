## 1. Основные понятия

Переменная связывает имя со значением; тип определяет допустимые операции. В Python различают целые числа, числа с плавающей точкой, строки, логические значения и составные коллекции.

## 2. Методы и инструменты

Входные данные пользователя изначально строковые; до расчёта нужны преобразование типа и проверка границ. Для денег важно учитывать округление и, при необходимости, десятичную арифметику.

## 3. Проверка качества и ограничения

Условные конструкции if/elif/else выбирают ветку по булеву выражению. Ошибки возникают при смешении присваивания и сравнения, неверных границах и пропущенных случаях.

## 8. Развёрнутый учебный пример и уточнения

### Пример условия на Python

```python
def discount_total(amount):
    if amount < 0:
        raise ValueError("Сумма не может быть отрицательной")
    if amount >= 5000:
        return round(amount * 0.9, 2)
    return round(amount, 2)

assert discount_total(4999) == 4999
assert discount_total(5000) == 4500
```

Для денежных расчётов в профессиональных решениях дополнительно рассмотрите `Decimal` и согласованное правило округления. Всегда оговаривайте, применима ли скидка ко всему заказу или отдельным товарам.
