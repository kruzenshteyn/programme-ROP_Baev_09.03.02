# Учебно-методический комплект: Информационные технологии (включая основы программирования)

**Статус:** разработанный проект для методического согласования, образовательная программа 09.03.02 «Информационные системы и технологии в цифровом бизнесе», 2026 год набора, очная форма. Документы в формате Markdown (`.md`); в комплекте ИТ есть синтетический CSV для выполнения лабораторных работ.

## Содержимое архива

- `00_Исходный_паспорт_MD.md` — конвертация предоставленного PDF-паспорта дисциплины.
- `01_РПД/РПД.md` — рабочая программа, темы, трудоёмкость, компетенции и учебные формы.
- `02_ФОС/ФОС.md` — оценочные средства, индикаторы, шкалы, билеты, кейсы и критерии.
- `03_Лекции/` — **18** самостоятельных конспектов лекций (каждая по 2 академических часа).
- `04_Практические_и_лабораторные/` — **18** подробных заданий (каждое по 4 академических часа), с вариантами, инструкциями и защитой.
- `05_Тесты/` — разделовые задания с выбором ответа, сводный банк **56** вопросов и отдельные ключи с объяснениями.
- `06_Материалы_и_шаблоны/` — рабочие примеры, шаблоны и данные для выполнения заданий.

## Результаты освоения

Лабораторные работы, расчётно-графическое задание, SQL, Python.

## Статус исходных и разработанных сведений

Часы, семестры, формы контроля и профильная компетентностная привязка сверены с предоставленными паспортом, планом и матрицей. Частные темы, детальные задания, тесты, шкалы и учебные кейсы разработаны в этом комплекте и требуют утверждения в установленном порядке. Проверка выявленных различий между паспортами и матрицей описана в `Замечания_для_согласования.md`.

**Источники:** `1_Концепция_ОПОП_09.03.02 ИСТ ЦБ.pdf`, `2_ЦКМВ_09.03.02_ ИСТ ЦБ.pdf`, `3_Учебный план_09.03.02_ИСТ_ЦБ.pdf`, `5_Матрица компетенций_ЦКМВ_09.03.02_ИСТ_ЦБ.pdf`, паспорт дисциплины; методические материалы архива `ИТ 2026 (2).zip`. Конвертации всех первоисточников находятся в отдельном архиве `Исходные_документы_MD.zip`.
