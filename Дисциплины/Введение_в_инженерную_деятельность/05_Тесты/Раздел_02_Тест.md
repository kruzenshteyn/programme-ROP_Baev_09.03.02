Выберите **один** правильный ответ для каждого вопроса. После прохождения теста разберите ошибки по учебному конспекту.

**1. Кто первично исследует потребности бизнеса?**

- **A.** Администратор печати
- **B.** Визуальный дизайнер иконок
- **C.** Специалист по закупке мебели

- **C.** Заключает трудовые договоры
- **D.** Ведёт рекламный канал продукта

**3. Что следует включить в описание процесса AS-IS?**

- **A.** Только цвет интерфейса
- **B.** Последовательность текущих работ, участников, входов и выходов
- **C.** Только список желательных функций

**4. Для чего строят модель TO-BE?**

- **A.** Для сокрытия ошибок отчётности
- **B.** Для определения цены компьютера
- **C.** Для описания желаемого изменённого процесса
- **D.** Для копирования текущего процесса без изменений

**5. Кто относится к заинтересованным сторонам проекта?**

- **A.** Только руководитель команды разработки
- **B.** Только владелец серверной комнаты
- **C.** Только автор технического задания

- **B.** Только пароль личной почты
- **C.** Только номер кабинета

- **A.** Рассчитать стоимость процессора

- **C.** Автоматически установить истинность требований

- **A.** Запретить журналирование изменений
- **B.** Убрать уникальные идентификаторы

**9. Что делает требование проверяемым?**

- **A.** Употребление слова «современный»

- **C.** Секретность постановки для команды

- **A.** Задокументировать ограничения и согласовать компромисс со сторонами
