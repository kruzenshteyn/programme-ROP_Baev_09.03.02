# Исходные материалы в формате Markdown

Конвертировано **18** документов: 6 основных PDF и 12 вспомогательных файлов из архива.

- `Основные/` — исходные концепция, целевая модель, план, матрица и паспорта обеих дисциплин.
- `Вспомогательные/` — PDF, DOCX и листы XLSX из `ИТ 2026 (2).zip`.
- `Основные/assets/` — изображения сложных исходных таблиц (плана и матрицы).

**Ограничения конвертации:** таблицы со сложными объединениями и межстраничными продолжениями могут потерять исходную геометрию; Excel-формулы приведены как текст, без пересчёта; графические элементы DOCX в Markdown не воспроизведены. Учитывайте это при утверждении учебно-методических материалов.
