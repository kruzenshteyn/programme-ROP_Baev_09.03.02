# Статус локальной сборки

- Источник целевого GitVerse: https://gitverse.ru/KAA85/programme-template; основная ветка `main`.
- Из веб-интерфейса подтвержден набор основных файлов: `README.md`, `ОВ.md`, `ОХОП.md`, `СДП.md`, `УП.md`, `ЦКМВ.md`, `инструкция-по-работе-с-репозиторием-РОП.md`.
- Выполнение `git clone` в среде подготовки завершилось ошибкой `Could not resolve host: gitverse.ru`.
- Поэтому представленная директория является **вновь собранной рабочей копией содержимого под целевую программу**, но **НЕ точным клоном**: исходная история коммитов `.git`, ветки, теги и подлинные файлы GitVerse не включены.
- Сохраненные названия ключевых файлов совпадают с видимой структурой GitVerse, но тексты перенесены и/или составлены из загруженных пользователем материалов 09.03.02.
- Для получения точного Git-клона и сохранения истории запустите на компьютере с доступом в сеть файл `Клонировать_и_наложить_материалы.sh`. Скрипт сначала выполняет `git clone`, затем переносит рабочие документы, создает отдельную ветку, **не делает commit и push**.
- Конвертация PDF в Markdown не является факсимильной: сложные табличные фрагменты сопровождаются изображениями; материалы РПД/ФОС — проекты на согласование.
